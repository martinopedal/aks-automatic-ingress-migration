## Release posture

This is a community migration toolkit, not a versioned product. Changes ship to `main` continuously. There is no semver release cadence. Customers should pin to a specific commit SHA in their own consumption—Terraform module ref, Bicep module path, or script invocation.

If a versioned release becomes useful, for example for distribution via the Terraform Registry, this changelog will switch to semver tags at that point. Until then, the source of truth is `main`.
